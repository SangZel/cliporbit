
# ClipOrbit

**The Internet's Best Live Moments**

ClipOrbit is an AI-powered streamer highlights platform designed to discover, edit, caption, and prepare entertaining moments for short-form video platforms.

## Current features
- FastAPI backend
- Health check endpoint
- Project foundation

## Planned features
- Video uploads
- AI transcription
- Interesting moment detection
- Vertical video editing
- Automatic captions
- Human approval before publishing
- YouTube integration

## Run locally

Install dependencies:

    pip install -r requirements.txt

Start the server:

    uvicorn app:app --reload

Open:

    http://127.0.0.1:8000
